# ProcureIQ Procurement Portal

A Streamlit demonstration portal for government-style procurement bidding.

## Features
- Sign up and sign in
- Bidder dashboard
- 20 sample tenders
- Search and filters
- Supplier eligibility checks
- Document upload and required-document tracking
- Bid submission validation
- Trust badges and payment SLA checklist

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
1. Push this repository to GitHub.
2. Open https://share.streamlit.io/
3. Create a new app.
4. Select the repository and branch.
5. Set Main file path to `app.py`.
6. Deploy.
